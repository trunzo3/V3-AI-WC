# Replit Prompt 10 — PDF Workbook Export

## What This Prompt Does

When a participant clicks "Download Workbook" in the sidebar, a branded PDF downloads to their computer containing every unlocked section with their notes. This prompt builds the server-side PDF generation and connects it to the existing sidebar button.

---

## 1. Install Puppeteer

Install Puppeteer in the API server package. Try the full package first:

```bash
pnpm --filter @workspace/api-server add puppeteer
```

If Puppeteer's bundled Chromium fails to install or run in the Replit environment, switch to puppeteer-core and use the system-installed Chromium:

```bash
pnpm --filter @workspace/api-server add puppeteer-core
```

Then find the system Chromium path (try `/usr/bin/chromium-browser` or `/usr/bin/chromium` or run `which chromium`) and pass it to `puppeteer.launch({ executablePath: '...' })`.

## 2. New API Endpoint

Create a new route file: `artifacts/api-server/src/routes/workbook.ts`

### GET /workbook/download

Requires participant session (check `req.session.participantId`). If not authenticated, return 401.

Steps:
1. Get participant from session (ID, email, name)
2. Get the participant's cohort (name, workbook_enabled)
3. If workbook_enabled is false, return 403 with message "Workbook download is not enabled for this cohort"
4. Get the cohort's sections from cohort_sections, ordered by level then sort_order, filtered to visible = true
5. Get the participant's unlocked sections from unlocked_sections
6. Filter to only sections that are unlocked (intersection of visible sections and unlocked sections). Also include sections where code_active is false (those are auto-unlocked)
7. For each unlocked section, fetch all notes from the notes table for this participant and section
8. Fetch all workflow maps from workflow_maps for this participant
9. For generic sections (section IDs starting with "generic_"), fetch the generic section data (title, content_blocks, goal_text) from generic_sections table
10. Build an HTML string from all this data (see section 4 below)
11. Render the HTML to PDF using Puppeteer (see section 5)
12. Return the PDF as a download:

```
Content-Type: application/pdf
Content-Disposition: attachment; filename="IQmeetEQ_Workbook_[CohortName]_[Date].pdf"
```

Register the route in the route index file:
```typescript
import workbookRouter from "./workbook";
router.use(workbookRouter);
```

## 5. Puppeteer PDF Generation

```typescript
async function generateWorkbookPdf(html: string): Promise<Buffer> {
  const browser = await puppeteer.launch({
    headless: true,
    args: ['--no-sandbox', '--disable-setuid-sandbox', '--disable-dev-shm-usage'],
  });

  try {
    const page = await browser.newPage();
    await page.setContent(html, { waitUntil: 'networkidle0' });

    const pdf = await page.pdf({
      format: 'Letter',
      printBackground: true,
      margin: { top: '0.75in', bottom: '0.75in', left: '0.85in', right: '0.85in' },
      displayHeaderFooter: true,
      headerTemplate: '<div></div>',
      footerTemplate: '<div style="width:100%;text-align:center;font-size:8pt;color:#6B7280;font-family:sans-serif;padding:0 0.85in;"><span style="float:left;font-weight:700;">IQmeetEQ</span><span>Workshop Workbook</span><span style="float:right;">Page <span class="pageNumber"></span></span></div>',
    });

    return Buffer.from(pdf);
  } finally {
    await browser.close();
  }
}
```

## 6. Wire the Sidebar Button

In the sidebar component, the "Download Workbook" link currently shows a toast saying "Workbook export coming soon." Replace that behavior:

**On click:**
1. Set a loading state (disable the button, change text to "Generating..." or show a small spinner)
2. Make a fetch request to GET /api/workbook/download with credentials included (to send the session cookie)
3. If the response is OK:
   - Get the response as a blob
   - Create a temporary download link
   - Extract the filename from the Content-Disposition header, or fall back to "IQmeetEQ_Workbook.pdf"
   - Trigger the download
   - Clean up the temporary link
4. If the response fails:
   - Show a toast: "Download failed. Please try again."
5. Reset the loading state

Remove the old toast placeholder code.
