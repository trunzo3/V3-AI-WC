## 1. Brand Mark — Fix Image Clipping

The logo/brand mark in the nav bar is being clipped on the top and bottom. The image has white padding baked in, but the component is cropping it. Fix: change the logo image element to use object-fit: contain (not cover or fill) so the full image including its padding renders without clipping. Do not crop, stretch, or alter the aspect ratio.

## 2. Sidebar — Unlocked Section Icons

Currently unlocked sections show no icon. Fix the sidebar to show three states:

- LOCKED: lock icon (this is already working correctly)
- UNLOCKED, NO NOTES: thin gold (#C8963E) outline circle (no fill) — signals "accessible but not yet worked on"
- UNLOCKED, HAS NOTES: filled gold (#C8963E) dot — signals "you've been here and worked on this"

The distinction between outline circle and filled dot gives participants a visual progress map without requiring them to understand what the dot means — unlocked sections always have something visible next to them.

- Add an "Add to level" dropdown button with options: Level 1, Level 2, Level 3, Level 4. When selected, the generic section is inserted into the current cohort's section list at the bottom of the chosen level. From there, the admin uses the normal up/down arrows to reorder it within the level.

## 4. Returning Participant Login — Fix Double-Click Bug

When a returning participant enters their email, the workshop code field should NOT be visible at all. Currently it shows an empty text input that the user must click into (or click Login once) before it disappears and shows the "Switch workshop" link.

Fix: When the email-blur check confirms the participant exists (via POST /auth/check-email), immediately:
- Hide the workshop code field entirely
- Show the "Switch workshop" link in its place
- Pre-fill the name field with the stored name
- The "Enter Workshop" / "Login" button should work on a single click — no double-click required

The code field should only appear if: (a) it's a brand new participant, or (b) a returning participant clicks "Switch workshop."
