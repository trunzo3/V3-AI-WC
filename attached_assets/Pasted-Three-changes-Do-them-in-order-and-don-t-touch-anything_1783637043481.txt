=== 2. Fix the sidebar collapse bug ===

File: artifacts/workshop/src/components/workshop/Sidebar.tsx

The effect that auto-expands the level containing the active section has two bugs:
  - `expanded` is in its dependency array, so collapsing a level immediately re-triggers the effect and reopens it.
  - `sections` is in its dependency array, and useListSections refetches every 4000ms returning a new array identity, so the effect re-fires on a timer.

Result: a participant viewing a Level 1 section can never keep Level 1 collapsed.

Fix: the effect must depend only on activeSectionId. It should expand the active section's level once, when the active section changes, and never again. A level the user manually collapses stays collapsed.

Verify by collapsing Level 1 while viewing a Level 1 section, then waiting ten seconds. It must stay closed.

=== 3. Add six block types to generic sections ===

Today a generic section body is a jsonb array where every block is {type:"text"|"prompt", content:string}. Admins pick from exactly two block types. Add six more.

Every existing block keeps working. Do not migrate or rewrite existing rows.

--- Block shapes ---

  { type:"prompt", content, label?, buttonLabel? }
      label overrides the gold "Prompt N" pill. buttonLabel overrides "Copy Prompt".
      Both optional. When absent, current behavior is unchanged.

  { type:"callout", variant:"stop"|"insight"|"rule"|"quote", title?, content }
      stop    — red banner, large centered title. Visual reference: the red "Stop Here" banner in Day1.tsx VerificationTest.
      insight — reuse the existing InsightBox component from SectionHeader.tsx.
      rule    — reuse the existing RuleBox component.
      quote   — reuse the existing DepthQuote component.

  { type:"cards", columns:2|3, cards:[{ title, body }] }
      Visual reference: the card grid in PowerFollowUps in Day1.tsx.

  { type:"steps", ordered:boolean, items:[{ title, body }] }
      Visual reference: the numbered-circle steps in VerificationTest in Day1.tsx.

  { type:"link", url, label, style:"button"|"text" }
      Opens in a new tab, rel="noopener noreferrer".

  { type:"field", fieldKey, label, placeholder?, multiline:boolean }
      Renders a NotesField with that fieldKey. Persists exactly like the existing notes field.

--- Two new columns on generic_sections ---

  showNotesField  boolean, not null, default true
      GenericSectionView currently appends a "Your Notes" field to every section unconditionally.
      When false, suppress it. Sections built entirely from `field` blocks don't want a stray notes box.

  badgeLabel  text, nullable
      Overrides the badge text in SectionHeader. When null, fall back to sectionType as today.
      Free text — "Orientation", "Pre-work", "Flagship Exercise".
      Style it like the existing "reference" badge.
